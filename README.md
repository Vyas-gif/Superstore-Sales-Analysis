
# Superstore Sales Analysis

## Project Overview
An end-to-end Data Analytics project that analyzes Superstore sales data using Python, SQL, and Power BI to identify business trends, sales performance, and profitability insights.

## Tools & Technologies
- Python — Pandas, NumPy, Matplotlib
- SQL — MySQL
- Power BI — Data visualization and DAX
- Jupyter Notebook — Data analysis

## Project Workflow
1. Data loading and cleaning using Python.
2. Exploratory Data Analysis (EDA).
3. SQL queries for business analysis.
4. Data visualization using Power BI.
5. Business insights and recommendations.

## Key Business Insights
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Total Customers: 793
- Profit Margin: 12.47%

### Important Findings
- Technology generated the highest category sales.
- The West region had the highest sales.
- Furniture had relatively low profitability.
- Tables, Bookcases, and Supplies recorded negative profits.
- Copiers generated the highest subcategory profit.
